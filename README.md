# PokeTactics
This is a pokedex android app. In the future, the idea is that users will also be able to upload their strategic teams for competitive Pokemon battles and share them with other users.

## 🛠️ Technologies and Tools

This project leverages a modern Android development stack, utilizing the following technologies, libraries, and tools:

### 💻 Programming Language
- **Kotlin** – Main language for Android development

### 🎨 UI Toolkit
- **Jetpack Compose** – Declarative UI toolkit for native Android development
- **Material3 (Compose)** – Google's Material You design system for building modern, adaptive UIs
- **ConstraintLayout for Compose** – For creating responsive UI layouts within Compose

### 📦 Jetpack Libraries
- **Core KTX** – Kotlin extensions for Android core APIs
- **Lifecycle & ViewModel** – Lifecycle-aware components for managing UI-related data
- **Navigation Compose** – Type-safe in-app navigation with Compose
- **Datastore Preferences** – Jetpack’s modern data storage solution replacing SharedPreferences

### 🧩 Architecture and Dependency Injection
- **Hilt** – Dependency injection framework based on Dagger
- **Hilt Navigation Compose** – Integrates Hilt with Jetpack Navigation and Compose

### 🔗 Functional Programming
- **Arrow Core** – Functional programming toolkit for Kotlin

### 🌐 Networking
- **Ktor Client** – Asynchronous HTTP client for making network requests

### 🧪 Testing
- **JUnit** – Unit testing framework
- **AndroidX Test (JUnit & Espresso)** – Instrumentation testing support
- **Compose UI Test** – Jetpack Compose testing utilities

### 🖼️ Image Loading
- **Coil (Compose)** – Lightweight and fast image loading library for Compose

### 🗃️ Database & Serialization
- **Realm Kotlin** – Mobile database for local data persistence
- **Kotlinx Serialization** – For JSON serialization and deserialization

### 🛠️ Development Tools
- **Gradle** – Build system
- **Android Studio** – Primary IDE
- **Git** – Version control
- **Java 17 / JVM Target 17** – Java version used for compilation
